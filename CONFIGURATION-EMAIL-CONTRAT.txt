FONDATION MARIA-V — CONFIGURATION E-MAIL DU CONTRAT

L'envoi SMTP par PHPMailer est maintenant intégré dans admin/contrats.php. L'administrateur doit d'abord enregistrer le contrat, préparer/imprimer le document en PDF depuis « Préparer le contrat », puis sélectionner le PDF dans le formulaire « Envoyer le contrat par e-mail ».

CONFIGURATION LOCALE (WampServer)
1. Dans C:\wamp64\www\maria-v\config\, copiez mail.local.php.example et renommez la copie mail.local.php.
2. Ouvrez mail.local.php dans un éditeur de texte.
3. Renseignez l'adresse Gmail exacte dans username et from_email. L'adresse doit être une véritable adresse Gmail valide ; vérifiez l'orthographe dans votre compte Google.
4. Renseignez le mot de passe d'application Gmail dans password. Ne l'envoyez jamais dans un chat et ne partagez jamais mail.local.php.
5. Laissez enabled à false jusqu'à ce que toutes les valeurs soient vérifiées. Passez ensuite enabled à true pour un test contrôlé.
6. Dans l'espace admin, ouvrez Gestion des contrats, sélectionnez la demande acceptée, enregistrez le contrat, préparez le PDF, puis envoyez-le au destinataire affiché. Testez d'abord avec une demande et une boîte e-mail que vous contrôlez.

Paramètres Gmail : smtp.gmail.com, port 587, TLS/STARTTLS, authentification avec l'adresse Gmail complète et le mot de passe d'application (pas le mot de passe habituel du compte).

Le formulaire accepte uniquement un fichier dont le type MIME est application/pdf, avec une limite de 10 Mo. Le statut du contrat devient « Envoyé au bénéficiaire » seulement si PHPMailer reçoit une confirmation de succès SMTP. En cas d'échec, le statut n'est pas changé et les détails techniques sont écrits dans le journal PHP du serveur ; le message affiché reste générique.

SÉCURITÉ
- Ne mettez jamais de vrai mot de passe dans mail.php, dans un ZIP ou dans un dépôt Git.
- mail.local.php est volontairement absent de l'archive ; créez-le localement à partir du modèle.
- L'adresse provisoire communiquée « www.sandrine93@gmail.com » doit être vérifiée dans le compte Google : le préfixe « www. » est inhabituel. N'activez pas l'envoi tant que l'adresse exacte n'est pas confirmée.
- La réception par le serveur SMTP ne garantit pas la livraison finale en boîte de réception.
- Aucun paiement en ligne n'est ajouté. La contribution mentionnée dans le contrat doit faire l'objet d'une validation juridique indépendante avant d'être demandée au bénéficiaire.
- Les informations d'identité et d'enregistrement de la Fondation doivent être vérifiées avant toute signature ou envoi contractuel.
